# FUTURE_PE_01 – AI Website Copy Generator

## 📌 Business Chosen
Glamour Studio – A premium hair and beauty salon in Banjara Hills, Hyderabad.

## ❗ Problem
Many local businesses struggle with:
- Unclear website messaging
- Generic content
- Low customer engagement

## 💡 Solution
Used AI tools to generate clear, engaging, and customer-focused website copy.

## 🧠 Prompt Logic
The prompts were designed to:
- Clearly define the target audience
- Set a specific tone (warm, confident, welcoming)
- Focus on customer outcomes instead of features
- Structure outputs (headline, services, CTA)

## 🛠 Tools Used
- ChatGPT
- Lovable

## 📂 Repository Structure
- prompts/ → Contains all input prompts
- outputs/ → Contains generated outputs
- assets/ → Contains screenshots

## 🚀 Outcome
Created structured, high-quality website copy that improves clarity, emotional connection, and user engagement.
